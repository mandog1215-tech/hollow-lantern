Conventions

Semantic versioning everywhere; the 0.x line tracks milestones in WorldForge's scheme; a completed milestone advances a version line but does not create a release. No codename is ever invented for a past version — where a project has none, this page says so. The full conventions live in the Engine Laboratory and each project's records.

Sources: the three releases registries and the records cited on the project pages. If this page and a registry disagree, the registry is right.
