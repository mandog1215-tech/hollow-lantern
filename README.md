# Hollow Lantern Interactive — unified studio website

The studio's single public website: Blacksite, AirportSim, and
WorldForge under one identity, plus the Engine Laboratory and
(forthcoming) Development Center.

Plain HTML + one shared `style.css`. No framework, no build step,
no JavaScript. Deployed by GitHub Pages from this repository.

## Standing rules (same as every studio site)

1. **Statuses change only on evidence.** A page's claims trace to
   a project record — a registry, changelog, tag, or verified run.
   If this site and a record disagree, the record is right and
   this site gets corrected.
2. **Three states are never blurred:** the game today / in
   development / long-term intent. Held and shelved are
   first-class statuses, stated in plain words.
3. **Qualified claims stay qualified.** The Engine Laboratory
   carries the Engine Registry's conclusion exactly: the audit
   found no evidence establishing a shared engine codebase or
   common code lineage; fragment-level reuse is not established
   either way. AirportSim's record: no public release is recorded
   in the available repository release records.
4. **Gaps stay visible** until closed by evidence.

## Build stages

- **Stage 1 (current):** studio home + studio page, Engine Lab
  index, and the Blacksite section as the representative project.
  AirportSim and WorldForge keep their existing sites until their
  sections are built in Stage 2; the old sites are untouched and
  remain live until the unified site passes acceptance and a
  cutover is separately authorized.
- Migration is governed by the studio's migration inventory
  (41 tracked components, no planned exclusions), kept with the
  studio records.
